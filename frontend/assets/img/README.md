# Guía de Recursos Gráficos - Distribuidora de Carnes San Martín

Esta carpeta contiene los archivos vectoriales y recursos gráficos del sistema.

## Especificaciones y Dimensiones Recomendadas

| Archivo | Uso | Formato Recomendado | Dimensiones Ideales | Relación de Aspecto |
| :--- | :--- | :--- | :--- | :--- |
| `logo.svg` | Logotipo principal en navbar, login y reportes | SVG o PNG con transparencia | 400 x 100 px (SVG vectorial escalable) | 4:1 |
| `hero-bg.jpg` | Fondo principal de la Landing Page | JPG / WebP optimizado (< 250 KB) | 1920 x 1080 px | 16:9 |
| `nosotros.jpg` | Imagen de sección institucional de calidad y trazabilidad | JPG / WebP (< 180 KB) | 1200 x 900 px | 4:3 |
| `producto-1.jpg` | Corte de Res Premium (Lomo, Picaña, Ribeye) | JPG / WebP (< 120 KB) | 800 x 800 px | 1:1 |
| `producto-2.jpg` | Cerdo Selecto y Cortes Especiales | JPG / WebP (< 120 KB) | 800 x 800 px | 1:1 |
| `producto-3.jpg` | Aves de Grano y Cortes Institucionales | JPG / WebP (< 120 KB) | 800 x 800 px | 1:1 |

## Recomendaciones de Estilo
- Fotografía con iluminación cálida, alto contraste y fondos oscuros o madera rústica para resaltar la frescura cárnica.
- Para el fondo del hero, aplicar un overlay oscuro con el color carbón (#1A1A1A a 75% de opacidad) para garantizar legibilidad del texto blanco.
- Evitar imágenes con saturación artificial o bordes sobreiluminados.
